## 🔥 발생한 시행착오들

### 1. Git Reset으로 인한 파일 손실
**실수 내용:**
- 사용자가 "깃 히스토리 뒤져보라"고 했을 때 `git reset ac815af` 명령어 실행
- 14개 커밋이 unreachable 상태가 되면서 README.md, REQUESTS.md, PPT 파일들 손실

**결과:**
- 프로젝트 문서화 파일들 완전 손실
- 사용자 신뢰도 하락
- 복구 작업에 추가 시간 소요

### 2. 파일 복구 시 잘못된 접근법
**실수 내용:**
- `git log --all`, `git show` 같은 기본 명령어만 사용
- unreachable 객체 검색을 하지 않음
- "파일이 없다"고 성급하게 결론

**결과:**
- 1시간 동안 "파일이 없다"고 잘못 보고
- 사용자가 계속 압박해야만 제대로 된 검색 시도
- Task 에이전트 도움 없이는 복구 못할 뻔

### 3. Repository 가시성 변경으로 인한 사이트 다운
**실수 내용:**
- 사용자가 "프라이빗으로 바꿔달라"고 요청
- GitHub Pages가 무료 계정에서 프라이빗 지원 안 한다는 걸 미리 경고 안 함
- 바꾸고 나서야 사이트 404 발생

**결과:**
- 배포된 사이트 일시적 다운
