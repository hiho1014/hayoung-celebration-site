# 하영이 완료 축하 사이트

간단한 1페이지 데모로, [완료]/[실패] 선택 후 스테이지를 클릭할 때마다 축하/낙담 시퀀스가 순차 재생됩니다. PC/모바일 모두 자연스럽게 동작합니다.

## 빠른 시작

- 로컬 미리보기
```
npx serve . --single
```

- 배포(요약)
  - GitHub Pages: 리포지토리 생성 → 코드 푸시 → Settings > Pages에서 브랜치/루트 설정
  - Netlify: 사이트 생성 후 폴더 드래그 앤 드롭
  - Vercel: 새 프로젝트 → 폴더 업로드 또는 Git 연동

## 사용 방법

1) 상단 문구 아래 버튼에서 [완료] 또는 [실패]를 선택합니다.
2) 효과는 3~5초 재생되지만 비차단입니다. 스테이지 빈 공간을 클릭하면 다음 장면으로 즉시 넘어갑니다.
3) 이미지와 말풍선은 총 3단계로 순차 노출됩니다.

## 파일 구조

```
index.html
styles.css
script.js
image/
  ├─ 이미지1 관계자-배경 제거.png
  ├─ 이미지2 커서맛피아-배경 제거.png
  └─ 이미지3 여러분-배경 제거.png
```

## 제작 정보

- 제작 날짜: 페이지 하단 섹션에 시스템 날짜 자동 표기
- 제작 시간: 약 3시 30분 ~ 5시 발표 전까지
- 다른 작업: https://www.mumumi-magic.com

## 라이선스/이미지

- 캐릭터 이미지는 배경제거된 제공 파일을 그대로 사용합니다. 외곽 상자/테두리를 두지 않고 원본을 강조합니다.
